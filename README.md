# Foggy Layers

Astro storefront and Cloudflare Worker for [foggylayers.com](https://foggylayers.com).

Run `npm ci`, then `npm run dev` for the website. Run `npm test`, `npm run build`, and `npm run check` before deploying. Cloudflare builds and deploys the main branch.

See [Facebook publishing setup](docs/facebook-publishing.md) for the private publisher, required Cloudflare secrets, and the disabled-by-default publishing flag.
